## 단순 구현

- 배열 선형 큐, 배열 원형 큐, 배열 원형 덱
- 이중리스트로 구현한 덱
    - 주의점: node가 하나일때 dequeue를 하면 front와 rear 둘 다 NULL로 만들어야함                    front를 한 칸 이동시켰을때 이동한 칸의 prev를 NULL로 만들기 (이동한 칸이 NULL아니라면) rear일 때는 next를 NULL로 만들기
- 단순리스트로 구현한 큐
    - 주의점: node가 하나일때 dequeue를 하면 front와 rear 둘 다 NULL로 만들어야함
- 큐,덱 여러개 사용하기
- 지역변수로 front와 rear 선언

## 교재 코드

- 큐를 이용한 피보나치
- 미로찾기 (bfs, dfs) → 교재에 코드가 있으나 그냥 템플릿 없이 문제가 나왔기 때문에 구현만 할 줄 알면 될거 같음

## 응용 문제

- front,rear 로 장난질 치는거 잘확인하기..
- bfs로 미로탈출하는 최단거리 찾기 (dfs 저번에 나왔으니 나올만하지..?)
- 3차원 미로탈출하기 (이정도면 거의 탈출맵)
- 미로 벽 부수고 탈출하기 (이정도면 근데 더 이상 미로가 아니지 않을까..)
- bfs로 영역 구하기
- queue 여러개 만드는 문제
- deque를 이용한 최솟값, 최댓값 트릭 (sliding window,,,, 근데 전에 round robin도 나왔으니..)
