## 단순 구현

- 배열 스택(템플릿에 top이 0으로 되어있지 않은지 확인)
- 단순 연결리스트로 구현한 스택
- 구조체 스택 (여러개의 정보를 담는..)
- 스택을 여러개 만들기 (top 역할을 하는 변수를 구조체에 넣기)
- 지역변수로 선언한 스택

## 응용 (교재 & 기출 & 해볼만한거)

- 괄호 검사
- 괄호의 값 계산하기
- 후위식 계산 (두자리 이상의 수 일때도.. 만약에 여기서 더 낸다하면 실수나 음수)
    - atoi, atof 함수 활용
- 후위식을 중위식으로 변환
      - 과정은 후위식 계산과 똑같지만 후위식 계산은 a + b의 결과값을 저장하는거고 중위식으로 변환할 때는 a + b라는 새로운 문자열을 만들어서 stack에 넣어야함..
- 중위식 계산 (중위 → 후위 변환 후 후위식 계산)
- 중위식을 후위식으로 변환
