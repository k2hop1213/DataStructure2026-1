# 📂 Data Structure: Stack (스택)

> **LIFO (Last-In-First-Out)**: 마지막에 들어온 데이터가 가장 먼저 나가는 후입선출 구조.

---

### 1. 개요 (Introduction)
스택은 데이터를 수직으로 쌓아 올린 형태의 선형 자료구조다. 데이터의 삽입과 삭제가 한쪽 끝(Top)에서만 이루어지는 것이 특징이다.



### 2. 주요 특성 (Key Features)
| 특성 | 설명 |
| :--- | :--- |
| **접근 제한** | 스택의 중간에 있는 데이터에 직접 접근할 수 없다. |
| **포인터 관리** | 현재 데이터의 위치를 가리키는 `top` 인덱스를 통해 모든 연산이 수행된다. |
| **동작 원리** | 접시를 쌓거나 책을 쌓는 것과 같은 논리로 작동한다. |

---

### 3. 주요 연산 (Operations)
스택의 핵심 인터페이스는 다음과 같은 5가지 연산으로 구성된다.

* **`push(data)`**: 스택의 맨 위에 새로운 데이터를 추가한다.
* **`pop()`**: 맨 위의 데이터를 제거하고 그 값을 반환한다.
* **`peek()` / `top()`**: 데이터를 제거하지 않고 맨 위 값을 확인만 한다.
* **`isEmpty()`**: 스택이 비어있는지 여부를 확인한다.
* **`isFull()`**: (배열 구현 시) 스택이 가득 찼는지 확인한다.

---

### 4. 실전 활용 (Real-world Applications)
스택은 주로 **이전 상태로의 복구**나 **역순 처리**가 필요할 때 사용된다.

1.  **브라우저 뒤로 가기**: 방문한 페이지 기록을 저장하고 역순으로 호출한다.
2.  **실행 취소 (Undo)**: 문서 편집기에서 마지막 작업을 취소하고 이전 상태로 되돌린다.
3.  **수식 검사**: 소괄호, 중괄호, 대괄호의 짝이 맞는지 검사한다.
4.  **역순 문자열**: 입력된 문자열을 뒤집어서 출력할 때 유용하다.
5.  **콜 스택 (Call Stack)**: 프로그램 실행 중 함수 호출과 복귀 주소를 관리한다.

---

### 5. 주의사항 (Considerations)
* **Stack Overflow**: 스택의 할당된 크기를 초과하여 데이터를 `push`할 때 발생한다.
* **Stack Underflow**: 비어있는 스택에서 데이터를 `pop`하려고 할 때 발생한다.
* 고정된 크기의 배열을 사용할 경우 메모리 낭비가 발생할 수 있으므로, 상황에 따라 동적 배열이나 연결 리스트를 고려해야 한다.
