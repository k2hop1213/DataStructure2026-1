## 트리 용어 정리

1. 차수 : 그 노드의 자식 노드의 개수, 차수의 최댓값이 그 트리의 차수
2. 레벨: 트리의 각 층에 레벨을 매긴 것
3. 트리의 높이: 트리가 가지고 있는 최대 레벨
4. 단말 노드: 자식이 없는 노드(= 터미널 노드)

## 이진 트리

- 자식의 개수를 2개로 제한한 트리
1. 포화이진트리 : 모든 레벨에 노드가 꽉 차있다
2. 완전이진트리:  마지막 레벨의 이전 레벨까지는 노드가 가득 차있고 마지막 레벨에서는 오른쪽에서 왼쪽 순으로 노드가 차있다
3. 균형이진트리: 좌우 서브 트리의 높이 차이가 1 이하인 트리 (↔ 경사 트리)

## 이진트리삭제 알고리즘

- 메모리를 해제해야하므로 서브 트리들을 먼저 삭제 하고 자기 자신을 제일 나중에 삭제해야한다

## 순회 알고리즘

- 트리를 순회한다(= 트리의 모든 노드를 한 번씩 다 방문한다)
- 자기 자신을 언제 출력하느냐에 따라서 전위,후위,중위가 나뉜다
- 전위 순회를 이용해서 중첩된 괄호 표현을 나타낼 수 있다 (앞뒤로 괄호 출력만 넣어주면 된다)
- 원형큐와 bfs를 이용하여 레벨 순서대로 출력하는 레벨 순회를 구현할 수 있다

## 노드의 개수 구하기

- 좌우 서브트리의 노드 개수를 구하고 거기다가 1(자기자신)을 더해서 반환

## 트리의 높이 구하기

- 좌우 서브트리 중 더 높은 서브트리의 높이에다가 1(자기자신)을 더해서 반환

## 트리 좌우 대칭 시키기

- swap 알고리즘을 통해서 오른쪽 자식과 왼쪽 자식을 바꾼다
- 자기 자신의 자식을 먼저 대칭 시켜도 되고 재귀호출로 서브트리의 노드들을 대칭 시킨 후 자기자신을 처리 해도된다

## 특정 노드의 레벨 구하기

- 레벨 1부터 시작해서 그 노드를 찾았으면 그때의 레벨을 반환
- 루트 노드를 먼저 처리하고 왼쪽 서브트리에서 그 노드를 못 찾았으면 오른쪽 서브트리에서 찾는다

# 이진 탐색 트리

## 정의

- 모든 노드는 유일한 키를 갖는다
- 왼쪽 서브 트리 키는 루트의 키보다 작다
- 오른쪽 서브 트리의 키는 루트의 키보다 작다
- 왼쪽과 오른쪽 서브 트리도 이진 탐색 트리이다.

## 탐색 연산

- 해당하는 키를 찾았으면 그 노드의 주소 반환
- 찾는 키가 루트의 키보다 작으면 왼쪽 서브트리 탐색
- 찾는 키가 루트의 키보다 크면 오른쪽 서브트리 탐색

## 삽입 연산

- 삽입할 노드의 키가 루트의 키보다 작다
    - 루트의 왼쪽 서브트리가 없으면 루트의 왼쪽 자식으로 삽입
    - 그게 아니면 왼쪽 서브트리에서 위치를 찾는다
- 삽입할 노드의 키가 루투의 키보다 크다
    - 루트의 오른쪽 서브트리가 없으면 루트의 오른쪽 자식으로 삽입
    - 그게 아니면 오른쪽 서브트리에서 위치를 찾는다
- 이진 탐색 트리는 유일한 키를 가지므로 그 이외의 경우면 메모리 해제

## 삭제 연산

- 삭제할 노드와 그 부모 노드를 반복문으로 찾는다
- 삭제할 노드를 찾지 못했으면 NULL 반환
- 삭제할 노드가 단말 노드인 경우
    - 삭제할 노드가 root인 경우 (parent == NULL)  root를 NULL로 바꾼다
    - 삭제할 노드가 부모노드의 오른쪽 자식인지 왼쪽 자식인지 판별 후 해당하는 포인터를 NULL로 바꾼다
    - 삭제할 노드의 메모리를 해제시킨다
- 삭제할 노드가 자식을 하나만 갖는 경우
    - 그 노드가 왼쪽인지 오른쪽인지 판별 후 그 자식과 부모 노드를 연결시킨다
    - 삭제할 노드의 메모리를 해제시킨다
- 삭제할 노드가 자식을 두 개 갖는 경우
    - 자기 자리를 대신할 후계자 노드를 찾는다 (오른쪽 서브트리에서 가장 작은 놈 or 왼쪽 서브트리에서 가장 큰 놈)
    - 삭제할 노드에 후계자 노드의 데이터를 덮어쓴다
    - 후계자 노드를 삭제한다
- 마지막으로 return root를 한다(root가 지역변수이므로 root의 값이 변경되었을때는 root에 다시 값을 넣어줘야함)

# 힙트리

- 최댓값과 최소값을 빨리 찾을 수 있도록 설계됨, 항상 루트에 최솟값 or 최댓값이 있다
- 힙트리는 완전 이진 트리이다
- 최대힙은 부모의 킷값이 자식의 킷값보다 항상 크거나 같다
- 최소힙은 부모의 킷값이 자식의 킷값보다 항상 작거나 같다

## 최대힙 삽입연산

- 일단 새로 삽입할 노드를 맨 마지막에 넣고
- 부모노드보다 자신이 작을때까지 값을 바꾸면서 올라감

## 최대힙 삭제연산

- 일단 맨 마지막에 있던 노드를 맨 위로 올린다
- 그리고 최대힙 조건을 만족할때까지 밑으로 내림
- 원래 루트의 값은 따로 저장해두었다가 마지막에 반환
