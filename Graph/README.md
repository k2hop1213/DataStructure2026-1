## 그래프 용어 정리

- 무방향 그래프 (양방향으로 갈 수 있음)
- 방향 그래프(한 방향으로만 갈 수 있음)
- 가중치 그래프: 간선에 비용이나 가중치가 할당된 그래프
- 부분 그래프: 그래프의 부분집합
- 정점의 차수: 정점에 연결된 간선의 수, 방향 그래프에선 in-dgree와 out-degree로 나눔
- 경로: 간선을 따라서 갈 수 있는 길
- 단순 경로: 반복되는 경로가 없음
- 사이클: 시작 정점과 종료 정점이 같음

## 최소비용 신장트리

- 신장트리: 그래프의 모든 정점을 포함하는 트리, 트리가 되려면 사이클이 없어야 하고,, 모든 정점을 연결해야 하므로 n개의 정점을 정확히 n-1개의 간선으로 연결한다
- 최소비용 신장트리: 가중치의 합이 최소인 신장트리

### Prim

- 가중치를 저장할 dist 배열과 이 정점이 MST에 포함됐는지 확인할 selected 배열 필요
- dist의 값은 INF(가중치 없음) selected의 값은 0 으로 초기화한다
- 시작점의 dist를 0으로 만들고 반복문에 들어감
- getMinVertex함수로 최소 가중치를 갖고있는 인덱스를 반환 (처음엔 0이겠져)
- 그리고 그 정점을 MST에 추가시킴
- 만약에 그 정점이 가지고 있는 가중치가 INF이면 함수 종료 (MST를 만들 수 없는 경우)
- MST에 추가시킨 정점과 연결된 정점되어있고 아직 선택되지 않은 정점들 중 현재 dist에 있는 값보다 적은 가중치를 가지고 있는 간선이 있으면 dist 배열의 값을 초기화시킨다
- 모든 정점이 선택된 경우면 MST 완성, 중간에 함수가 종료됐으면 완성시키지 못함

### Kruskal

- 가중치를 기준으로 오름차순으로 정렬함(최소힙 사용), 집합의 개수를 정점의 개수로 초기화하고 parent 배열의 초기값을 -1로 초기화한다
- 힙트리 구조체에 들어가야할것 (가중치, 출발지, 목적지)
- 그리고 가중치가 작은것들부터 힙트리에서 pop을 하면서 선택을 한다 (간선의 개수가 n-1이 될때까지)
- 그러나 cycle이 생기지 않게 하기 위해서 각 정점의 최종 부모를 역추적해서 비교한다
- 최종 부모가 같지 않으면 간선을 연결하여 MST에 추가하고 parent 배열에다 저장 집합의 개수를 1개 줄인다
- 최종 부모가 같으면 간선을 연결하지 않는다

### Dijkstra

- 시작 정점에서 다른 모든 정점까지의 최소 경로(가중치들의 합)를 구하는 알고리즘
- dist 배열에 들어가는것 (시작정점에서 그 정점까지의 최소경로가 몇이냐)
- Prim 알고리즘과 전체적인 구조는 똑같으나 dist 배열을 갱신하는 조건이 다름
- 현재 선택한 정점까지의 최소 경로와 (dist[v])현재 선택한 정점과 다른 정점까지의 가중치의 합(adj[v][w])이 그 다른 정점의 최소경로(dist[w])보다 작은지 비교

### Floyd

- 모든 정점에 대해서 다른 정점까지의 최소 경로를 구하는 알고리즘
- 모든 출발지와 도착지에 대해서 모든 경유지에 대한 가중치에 합들을 비교하며 최소값을 저장한다.
